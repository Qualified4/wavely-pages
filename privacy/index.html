01. 적용 범위와 운영자

Wavely의 운영자·개발자(Qualified4, 문의: davin3377@gmail.com)는 개인용 Windows 음악 편집 앱과 이 소개 홈페이지의 데이터 처리 방식을 아래와 같이 안내합니다. 앱은 공개 배포하지 않습니다. 홈페이지에는 계정 생성, 결제, 광고, 분석·추적 스크립트가 없습니다.

로컬 편집 기능은 구현되어 있으며, YouTube OAuth·업로드·플레이리스트 기능은 개발 및 검증 중입니다. 아래 계정 연동 설명은 시행일에 확인한 개발 코드의 처리 방식이며, 실제 Google 계정 연결과 업로드의 전체 동작 검증이 끝났다는 뜻은 아닙니다.

02. 처리하는 정보와 이용 목적

  • Google OAuth 인증: 사용자가 선택한 Google 계정의 동의를 받아 YouTube API 접근 권한을 얻습니다. Google 비밀번호는 앱이 받지 않습니다. 별도의 Gmail·연락처·Drive 권한을 요청하지 않습니다.
  • 채널 정보: YouTube 채널 ID·이름, 연결 상태와 갱신 시각을 저장해 업로드 대상 계정을 표시하고 확인합니다.
  • 플레이리스트: ID·제목·공개 범위·항목 수·썸네일 URL과 영상 등록 정보를 조회·저장해 대상 선택과 등록 상태 확인에 사용합니다.
  • 선택한 영상: 사용자가 선택한 로컬 MP4 및 제목·설명·태그·공개 범위·아동용 여부 등 업로드 설정을 YouTube로 보냅니다. 일부 공개를 기본으로 하며 실제 공개 상태는 YouTube가 결정할 수 있습니다.
  • 업로드 기록: 영상 ID, 채널·트랙 연결 정보, 파일 경로·크기·해시, 처리 상태·전송 진행률·오류·시각 및 플레이리스트 등록 상태를 로컬에 저장합니다. 업로드 재개에 필요한 세션 정보도 처리합니다.

03. 요청 권한과 인증 정보 보관

개발 코드에서 요청하는 범위는 https://www.googleapis.com/auth/youtube.force-ssl 하나입니다. 채널 확인, 플레이리스트 조회, 영상 업로드·상태 조회 및 플레이리스트에 영상 추가에 사용합니다. 이 범위는 YouTube 동영상, 평가, 댓글, 자막 등을 조회·수정·삭제할 수 있는 넓은 권한이며, 읽기 전용이나 업로드 전용 권한이 아닙니다. Wavely는 위에 설명한 기능을 위해서만 사용합니다. 거부하면 해당 연동 기능을 사용할 수 없으며 로컬 편집은 계속 가능합니다.

기본 브라우저의 Google 인증 화면과 로컬 루프백 콜백을 사용하며, PKCE와 state 확인을 구현합니다. 액세스 토큰·갱신 토큰·가져온 OAuth 클라이언트 설정과 업로드 세션 정보는 앱 데이터 폴더의 credentials 아래에 Windows 사용자 계정에 연결된 DPAPI 암호화 파일로 보관하도록 구현되어 있습니다. 이 정보는 홈페이지로 전송되지 않습니다. 원본으로 가져온 OAuth 설정 JSON은 자동 삭제하지 않으므로 사용자가 별도로 관리해야 합니다.

토큰 만료가 임박하거나 API 인증이 거부되면 Google 토큰 엔드포인트로 갱신을 요청하고 저장값을 갱신합니다. 갱신이 거부되면 재인증이 필요합니다. 일반 라이브러리 DB·미디어·로그 전체를 암호화한다고 주장하지 않으며, Windows 계정과 PC의 보호는 사용자가 관리해야 합니다.

04. 로컬 편집 데이터와 보관

음악 소스 URL·제목·챕터, 선택 구간·트랙·북마크·메타데이터·편집 설정·작업 기록은 앱 데이터 폴더의 library.sqlite3에 저장됩니다. 가져온 파일과 다운로드한 미디어는 media, 파형과 미리보기는 cache, 앨범아트는 artwork, 진단 기록은 logs에 보관됩니다. MP3·MP4는 사용자가 지정한 출력 폴더에 저장되며 앱 데이터 폴더 밖에 있을 수 있습니다.

파일·편집 정보와 채널·플레이리스트·업로드 기록은 사용자가 삭제할 때까지 남을 수 있습니다. 자동 만료 삭제 기능은 현재 확인되지 않았습니다. 계정 연결 해제만으로 이 기록이나 미디어가 전부 삭제되지는 않습니다.

05. 데이터 전송과 외부 서비스

별도의 Wavely 운영 서버·클라우드 DB는 없습니다. Google 인증 정보와 계정 데이터는 인증·갱신·권한 철회 및 사용자가 요청한 YouTube API 기능에 필요한 범위에서 사용자의 PC와 Google API 사이에 직접 전송됩니다. 개발자가 이 데이터를 수신하는 서버는 운영하지 않습니다.

YouTube 가져오기는 외부 도구 yt-dlp를 사용하며, OAuth 업로드 기능과 별개의 경로입니다. 선택한 영상 URL을 처리하면서 YouTube·Google의 미디어 서버/CDN에 접속하고 IP 주소와 요청 정보가 전달될 수 있습니다. 영상 프레임을 가져올 때도 네트워크 요청이 발생합니다. FFmpeg·ffprobe는 편집·변환을 로컬에서 수행합니다. 사용자는 내려받기·편집·업로드 권리와 YouTube 약관을 직접 확인해야 합니다.

홈페이지는 GitHub Pages에서 호스팅됩니다. 사이트 운영자는 자체 쿠키·분석·광고·추적 스크립트를 추가하지 않지만, GitHub는 호스팅 제공에 필요한 IP 주소 등의 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 이 홈페이지는 Google 계정 로그인이나 토큰을 받지 않습니다.

Google 사용자 데이터를 판매하거나 광고·프로파일링·범용 AI 모델 학습에 사용하지 않으며, 다른 사용자에게 제공하지 않습니다. 지원 이메일로 직접 보낸 내용은 문의 응대에 사용되며 Gmail을 통해 처리됩니다. 토큰·비밀번호·OAuth 설정 파일을 이메일로 보내지 마세요.

06. 연결 해제, 권한 철회와 삭제

  1. 앱에서 연결 해제: 개발 중인 앱의 YouTube 업로드 → YouTube 계정에서 해당 채널의 연결 해제 및 인증 정보 정리를 선택합니다. Google 권한 철회를 시도하고 해당 계정의 저장된 토큰과 업로드 세션 인증 정보를 로컬에서 삭제합니다. 네트워크 실패 시 Google 측 철회는 보장되지 않으므로 다음 단계도 확인하세요.
  2. Google에서 철회: Google 계정의 서드 파티 연결 관리에서 Wavely를 선택해 액세스 권한을 삭제합니다. 이는 PC의 저장 기록이나 이미 업로드한 영상을 자동 삭제하지 않습니다.
  3. 로컬 정보 전체 삭제: 진행 중인 작업을 마치고 앱을 완전히 종료합니다. 설정에서 확인한 앱 데이터 폴더(기본 Windows 경로는 %APPDATA%\app.wavely.desktop, 별도 지정 시 다를 수 있음)를 파일 탐색기에서 삭제합니다. 여기에는 DB와 그 부속 파일, 채널·플레이리스트·업로드 기록, 인증 파일·가져온 OAuth 설정 사본, 캐시·아트·다운로드 미디어·로그가 포함됩니다. 전체 라이브러리가 사라지므로 필요한 파일을 먼저 보관하세요.
  4. 외부 파일과 출력: 별도 출력 폴더의 MP3·MP4, 앱 외부 원본, 처음 가져온 OAuth JSON 및 사용자가 만든 백업은 자동 삭제되지 않습니다. 파일 탐색기에서 개별 삭제하고 필요한 경우 휴지통도 비웁니다.
  5. YouTube의 데이터: 업로드한 영상과 플레이리스트 항목은 YouTube Studio 또는 YouTube에서 직접 삭제합니다. 앱 연결 해제와 로컬 삭제는 Google에 이미 전송한 영상을 지우지 않습니다.

현재 앱에는 계정 연결 해제와 별개로 Google 유래 기록만 일괄 삭제하는 전용 기능이나 자동 보관 기간 정리가 확인되지 않았습니다. 앱 데이터 폴더 삭제는 로컬 기록 전체를 삭제하는 방법입니다. 도움이 필요하면 아래 지원 주소로 문의하세요.

07. Google·YouTube 정책

Wavely의 Google API 데이터 사용·전송은 Google API Services User Data Policy와 해당되는 Limited Use 요건을 준수해야 합니다. 데이터는 위에 공개한 사용자 기능에만 사용하며 판매·광고에 이용하지 않습니다. 이 안내가 Google의 검증 또는 정책 준수 승인을 의미하지는 않습니다.

YouTube 연동에는 YouTube API Services Terms of Service 및 개발자 정책이 적용되며, 사용자는 YouTube 서비스 약관에도 구속됩니다. Google의 처리는 Google 개인정보처리방침, 홈페이지 호스팅은 GitHub 개인정보처리방침을 참고하세요.

08. 변경과 문의

데이터 처리 방식이나 권한이 변경되면 이 방침의 시행일과 내용을 갱신합니다. 새로운 목적의 Google 데이터 접근에는 필요한 사전 고지와 동의를 거쳐야 합니다.
